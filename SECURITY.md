# Security Policy

This repository contains an educational prototype. Do not use it as a production security control.

## Scope

Use the project only with synthetic data, systems you own, or systems you are explicitly authorised to assess. Review the README for project-specific limits.

## Supported versions

Only the latest version on the default branch is supported.

## Reporting a vulnerability

Do not post credentials, private captures, or sensitive vulnerability details in public issues. If GitHub's private vulnerability reporting option is available for this repository, use it. Otherwise, open a public issue asking for a private reporting channel without including sensitive details.
